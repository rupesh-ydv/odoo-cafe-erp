# Product Accessories — Odoo 19

## Features
- Configure accessory products from the Product Template form.
- Dedicated Product Accessories menu under Sales > Products.
- Sequence, active state, website visibility, required flag and maximum quantity.
- eCommerce product-page accessory cards.
- Add the main product and selected accessories to the cart together.
- Server-side validation of accessory relationships.

## Installation
1. Copy `product_accessories` into an Odoo custom addons directory.
2. Restart Odoo.
3. Update the Apps list.
4. Install **Product Accessories**.
5. Go to Sales > Products > Products.
6. Open a product and use the **Accessories** tab.
7. Add sellable accessory products.
8. Publish the products on the website.
9. Open the main product page and test **Add to Cart with Accessories**.
